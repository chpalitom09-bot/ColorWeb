ColorWeb Installer

Attrapez n'importe quelle couleur.

ColorWeb est une extension Chrome. Vous pointez un endroit de l'écran, le code couleur est copié. Sur n'importe quel site.

Installer l'extension

Survolez les couleurs à droite, puis cliquez pour en attraper une.

#7AA2FF

Pointez ce que vous voyez.

Une loupe suit le curseur et grossit les pixels pour viser la couleur exacte.

Un clic, c'est copié.

Le code est dans le presse-papiers, en HEX, RGB ou HSL, prêt à coller dans votre code ou votre outil de design.

Rien n'est perdu.

Vos dernières couleurs restent dans l'historique de l'extension pour les retrouver plus tard.

HEX

RGB

HSL

Pensée pour travailler vite.

Partout dans Chrome

Si c'est à l'écran, vous pouvez le pointer : sites, images, vidéos, PDF ouverts dans le navigateur.

Précise sur le texte

Le mode texte ignore le lissage des lettres et récupère leur vraie couleur, pas un pixel flou.

Raccourci clavier

Lancez la pipette sans ouvrir le menu, depuis n'importe quelle page.

Pour les créatifs et les devs

Copiez le format dont vous avez besoin : HEX pour le CSS, RGB ou HSL pour le reste.

Ajoutez-la à Chrome.

Le code est sur GitHub, la publication sur le Chrome Web Store arrive.
